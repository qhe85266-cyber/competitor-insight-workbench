# 降级策略 — 竞品洞察工作台 AI 层

产品目标：无 Key 也能完整演示主路径；失败行为可解释；**人审闸门始终保留**（模型/fixture 不得自动 `accepted`）。

错态文案优先复用设计规格 §3.7。

---

## 1. 无 API Key

| 项 | 说明 |
| --- | --- |
| **触发** | 未配置模型凭证；或用户点「加载示例数据」/ Demo Mock 开 |
| **UI** | TopBar 副标或徽标：`简历 Demo · Fixture 数据`；生成走本地 fixture，不发起真实调用 |
| **回退 fixture** | **是** → `fixtures/demo-pack.json` |
| **可演示** | **是**：对比表 + 3 张机会卡完整可点；证据可锚定单元格 |
| **人审** | **仍在**：初始 `review=pending`，采纳/驳回仅本地状态 |

---

## 2. 超时

| 项 | 说明 |
| --- | --- |
| **触发** | 模型请求超过产品超时（建议单次 ≤ 60s，可配置） |
| **UI** | Alert：`生成失败，请重试。当前为本地示例数据模式。` +「重试」；保留上次成功结果（若有） |
| **回退 fixture** | **不自动覆盖**已有审阅数据。无任何机会时提供显式「加载示例数据」 |
| **人审** | **仍在**；超时结果不写入 `accepted` |

---

## 3. 解析失败（非法 JSON / schema 校验失败）

| 项 | 说明 |
| --- | --- |
| **触发** | 非 JSON、非数组、缺必填、`title`/`summary` 超长或空、`evidence` 空、`confidence`/`review` 枚举非法等 |
| **UI** | `生成失败，请重试。`；技术详情折叠（勿展示密钥/完整 prompt） |
| **回退 fixture** | **不自动**。显式「重试」与「加载示例数据」 |
| **人审** | **仍在**；非法输出**不得**进入待审列表（宁可空，不可脏数据） |

---

## 4. 证据引用无效

| 项 | 说明 |
| --- | --- |
| **触发** | `source_ref` 无法在 `comparison.cells` 解析；或 `quote` 不是对应单元格子串 |
| **处理** | 入库前过滤：仅保留引用有效的机会；提示「已剔除 N 条无效引用」。**禁止**静默改写 `source_ref` |
| **若过滤后 0 条** | 同解析失败：错态 + 显式加载示例 |
| **人审** | **仍在**；无效引用不得被采纳为可信结论 |

---

## 5. Fixture 缺失

| 项 | 说明 |
| --- | --- |
| **触发** | `fixtures/demo-pack.json` 404 或 JSON 损坏 |
| **UI** | 设计规格文案：`示例数据未就绪，请检查 fixture 或点击重试。` |
| **人审** | 无机会卡可审；不伪造卡片 |

---

## 横切原则

- 不把 API Key 写入仓库或前端包。
- 不绕过 OAuth。
- Fixture / 模型产出一律从 `review=pending` 起跳。
- 导出 Markdown：仅含**已采纳**机会 + 完整对比表（见设计规格）。
